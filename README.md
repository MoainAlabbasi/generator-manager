# Generator Manager - مدير المولدات

تطبيق Android احترافي لإدارة المولدات الكهربائية، تتبع وقت التشغيل، إنتاج الكهرباء، ومخزون الديزل.

## المميزات

- **واجهة عربية كاملة**: تصميم RTL (من اليمين إلى اليسار) مع Material Design 3
- **العمل بدون إنترنت**: قاعدة بيانات محلية SQLite
- **لوحة تحكم شاملة**: عرض الديزل المقدر ومتوسط الكفاءة
- **التسجيل اليومي الذكي**: جلب تلقائي للقراءة السابقة عند اختيار العداد
- **إدارة التوريد**: تسجيل توريدات الديزل الواردة
- **الإعدادات**: إضافة مولدات وعدادات جديدة
- **التقارير**: عرض آخر 30 سجل مع تلوين تلقائي حسب الكفاءة
- **النسخ الاحتياطي**: تصدير قاعدة البيانات

## التقنيات المستخدمة

- **Framework**: Flet (Flutter for Python)
- **Database**: SQLite3
- **UI Design**: Material Design 3, RTL Layout
- **CI/CD**: GitHub Actions (بناء APK تلقائي)

## التشغيل المحلي

### المتطلبات

- Python 3.10 أو أحدث
- pip (مدير حزم Python)

### خطوات التشغيل

1. **استنساخ المستودع**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/generator-manager.git
   cd generator-manager
   ```

2. **تثبيت المتطلبات**:
   ```bash
   pip install -r requirements.txt
   ```

3. **تشغيل التطبيق**:
   ```bash
   python main.py
   ```

   أو باستخدام Flet:
   ```bash
   flet run main.py
   ```

## بناء APK محلياً

### المتطلبات الإضافية

- Flutter SDK (مثبت ومضاف إلى PATH)
- Android SDK

### خطوات البناء

1. **تثبيت Flet**:
   ```bash
   pip install flet
   ```

2. **بناء APK**:
   ```bash
   flet build apk --verbose
   ```

3. **الملف الناتج**:
   سيتم إنشاء ملف APK في:
   ```
   build/apk/app-release.apk
   ```

## البناء التلقائي عبر GitHub Actions

عند رفع الكود إلى فرع `main`، سيتم تشغيل GitHub Actions تلقائياً لبناء APK. يمكنك تحميل الملف الناتج من صفحة Actions في المستودع.

## هيكل قاعدة البيانات

### جدول `generators`
- `id`: المعرف الفريد (Primary Key)
- `name`: اسم المولد

### جدول `meters`
- `id`: المعرف الفريد (Primary Key)
- `generator_id`: معرف المولد (Foreign Key)
- `type_name`: نوع العداد (مثل: شاشة دمج، محول تيار)
- `last_reading`: آخر قراءة مسجلة

### جدول `diesel_inventory`
- `id`: المعرف الفريد (Primary Key)
- `date`: تاريخ التوريد
- `quantity_in`: الكمية الواردة (لتر)
- `station_name`: اسم المحطة
- `receipt_no`: رقم الإيصال

### جدول `daily_logs`
- `id`: المعرف الفريد (Primary Key)
- `date`: تاريخ السجل
- `meter_id`: معرف العداد (Foreign Key)
- `prev_reading`: القراءة السابقة
- `curr_reading`: القراءة الحالية
- `production`: الإنتاج (محسوب تلقائياً)
- `diesel_consumed`: الديزل المستهلك
- `efficiency`: الكفاءة (محسوبة تلقائياً)

## الاستخدام

### 1. لوحة التحكم (الرئيسية)
- عرض الديزل المقدر في الخزان
- عرض متوسط الكفاءة لليوم الحالي
- زر سريع لإضافة سجل يومي

### 2. التسجيل اليومي
- اختيار المولد
- اختيار العداد (يتم جلب القراءة السابقة تلقائياً)
- إدخال القراءة الحالية والديزل المستهلك
- حفظ السجل (مع التحقق من صحة البيانات)

### 3. التوريد والإعدادات
- **توريد الديزل**: تسجيل توريدات جديدة
- **الإعدادات**:
  - إضافة مولد جديد
  - إضافة عداد جديد لمولد موجود
  - تصدير قاعدة البيانات للنسخ الاحتياطي

### 4. التقارير
- عرض آخر 30 سجل
- تلوين تلقائي:
  - **أخضر**: كفاءة > 3.2
  - **أحمر**: كفاءة < 3.0
  - **أسود**: كفاءة بين 3.0 و 3.2

## الحسابات التلقائية

- **الإنتاج** = القراءة الحالية - القراءة السابقة
- **الكفاءة** = الإنتاج / الديزل المستهلك
- **الديزل المقدر** = إجمالي التوريد - إجمالي الاستهلاك
